# 진짜 뇌 실험 기록

`BRAIN=real`(FlyWire v783 배선, Shiu 등 2024의 수식)로 해 본 실험의 결과를 모았다. 발표에서 근거로 쓸 숫자와, 건드리면 안 되는 것을 적는다. 숫자는 뉴런 하나의 초당 발화 수이고, 따로 적지 않으면 씨앗 5개의 평균이다.

## 1. 맛 뉴런을 하나씩 켜 본 결과 (11/23)

단맛(LB3c)만 초당 120번 자극하면 먹기 뉴런이 62.5로 발화한다. 여기에 다른 맛 뉴런을 같이 켰을 때:

| 같이 켠 뉴런 (표의 이름) | 그것만 120 | 단맛 120 + 40 | + 80 | + 160 | 판정 |
|---|---|---|---|---|---|
| 쓴맛 전체 (LB1a~d) | 0 | 43.7 | 7.6 | 0.0 | 먹기를 막는다 |
| LB1e ("glutamate") | 0 | 52.9 | 26.3 | 3.0 | 먹기를 막는다 |
| 물 (LB3a) | 0 | 66.0 | 55.4 | 39.7 | 조금 막는다 |
| 짠맛 (LB3d, "high_salt") | 83.2 | | | 114.5 | 먹기를 늘린다 |
| LB3b ("sugar/low_salt") | | | 74.2 | | 먹기를 늘린다 |

- **표에 짠맛이라고 적힌 뉴런은 이 모델에서 먹기를 막지 않는다.** 오히려 단맛보다 세게 먹게 만든다.
- 그래서 게임의 `BR_SALT`는 LB1e에 연결했다. 짠맛만 주면 먹지 않고, 단맛과 같이 주면 먹기가 줄어든다. LB1e가 실제로 짠맛 뉴런이라는 뜻은 아니다.
- 물은 먹기를 늘리지 않는다.

## 2. 폭주 상태

- 이 뇌는 어떤 자극에서는 스스로 계속 발화하는 상태에 빠진다. 한 틱(50ms)에 약 43,000번 발화하고(정상 최대는 약 6,500번), 자극을 꺼도 멈추지 않는다. 그동안 한 틱 계산에 100~300ms가 걸린다.
- 일으키는 것: 냄새 뉴런 거의 전부(초당 2~15번만 줘도), LB1e를 초당 90번 이상 계속, LB3b를 80번 이상, 모든 뉴런에 약한 배경 발화를 넣었을 때.
- 지금 게임이 쓰는 자극(다가옴, 단맛, 쓴맛, 물, 짠맛 60 이하)에서는 60초씩 여러 번 돌려도 일어나지 않았다.
- 대비: 한 틱의 발화가 20,000번을 넘으면 뇌를 처음 상태로 되돌린다(`brain/brain_real.c`).
- **하지 말 것:** `BR_SALT`의 최대 빈도를 70 위로 올리기, 냄새 뉴런을 그대로 연결하기, 배경 발화 켜기.

## 3. 상수가 달라져도 반응이 유지되는가

게임이 기대는 사실 일곱 가지(자극이 없으면 조용함, 도주가 자극 세기에 따라 커짐, 한쪽 다가옴에 반대쪽 회전만, 양쪽이면 후진, 단맛 문턱, 쓴맛의 억제)가 조건을 바꿔도 성립하는지 씨앗 5개로 보았다.

| 조건 | 결과 |
|---|---|
| 뉴런마다 문턱과 막 시상수를 ±10% 흩뜨림 | 일곱 가지 모두 5/5 |
| ±20% 흩뜨림 | "양쪽이면 후진"만 4/5, 나머지 5/5 |
| 시냅스 세기 ±10% | 모두 5/5 |
| 시냅스 세기 0.8배 | 후진이 사라지고(0/5), 먹기가 기준 아래로 내려감(1/5) |
| 시냅스 세기 1.2배 | 왼쪽 다가옴의 오른쪽 회전이 기준 아래로 내려감 |
| 시간 간격 0.2ms, 0.5ms | 반응은 같고, 속도 이득은 없음(계산의 약 90%가 신호 전달이라서) |

- 반응은 뉴런 상수의 ±10% 흔들림에는 버틴다. 가장 약한 출력은 후진(뉴런 4개)과 방향 전환이다.
- 시냅스 하나의 세기(0.275mV)를 20% 바꾸면 게임의 기준선을 넘나든다. 이 값은 바꾸지 않는다.
- 신경전달물질별로 시상수를 달리하는 것은 근거가 될 공개 수치를 찾지 못해 하지 않았다.

## 4. 학습 시제품 (코드는 아직 넣지 않음)

버섯체에서 "냄새 + 벌"을 짝지으면 그 냄새에 대한 출력 뉴런의 반응이 줄어드는지 시험했다.

| 훈련 | 냄새 A에 대한 접근 출력 뉴런 |
|---|---|
| 훈련 전 | 43.8 |
| A + 벌(도파민 뉴런 자극) 2초 뒤 | 0.0 |
| A만 2초(벌 없음) 뒤 | 43.3 |

- 벌을 준 냄새에만 반응이 사라졌다. 다른 냄새 B는 12.8에서 9.2가 됐다.
- **단서가 크다.** 냄새 뉴런을 자극하면 폭주해서, 냄새를 버섯체 세포에 직접 넣었다. 벌도 도파민 뉴런에 직접 넣었다. 학습을 켠 동안에는 연결 세 묶음을 꺼야 했다. 그래서 학습을 켠 뇌는 공개된 배선 그대로가 아니다.
- 지금 미니게임 중 학습을 쓰는 것이 없어서 코드는 합치지 않았다. 쓸 곳이 정해지면 합친다.

## 5. 배선을 섞은 뇌와의 비교 (11/23)

같은 시뮬레이터에 배선만 섞은 뇌를 넣었다. 뉴런 수, 연결 수, 뉴런마다 나가는 연결 수와 들어오는 연결 수, 보내는 쪽의 세기와 부호는 그대로 두고, 받는 뉴런만 전체에서 뒤섞었다(`make brain-compare`).

| | 진짜 배선 | 섞은 배선 |
|---|---|---|
| 왼쪽 다가옴 150: 도주 / 오른쪽 회전 | 195 / 15 | 0 / 0 |
| 양쪽 다가옴 150: 후진 | 24.4 | 0 |
| 단맛 120: 먹기 | 66 | 0 |
| 예제 게임의 초파리 점수(씨앗 10개, 120점 만점) | 101 ± 12 | 27 ± 17 |

- 섞은 뇌에서는 모든 자극에 출력 뉴런이 발화하지 않는다. 게임에서 초파리는 한 번도 움직이지 않았고, 27점은 가만히 서 있을 때의 점수다. 규칙으로 만든 가짜 뇌는 106 ± 10이다.
- **말할 수 있는 것:** 같은 계산에 배선만 섞으면 초파리가 반응하지 않는다. 반응은 뉴런 모델이 아니라 배선에서 나온다.
- **말하면 안 되는 것:** "정밀한 배선 하나하나가 있어야 피한다." 연결의 75%만 섞은 뇌는 여전히 99점을 냈다(섞는 씨앗 하나로만 해 본 것이다).
