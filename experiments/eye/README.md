# 눈 실험 기록 (11/27)

게임 코드가 아니다. "초파리에게 눈을 달면 지금 뇌(FlyWire v783 + Shiu 등 2024의 식)가 물체를 보고 쫓아오는가"를 보려고 한 실험의 도구와 결과다. `make`가 빌드하지 않는다.

## 결론

- **눈으로 쫓아오게 하는 것은 이 모델에서 되지 않았다.** 학습된 시각 모델(flyvis)의 출력을 진짜 뇌에 넣은 모든 경우에서 물체 뉴런 LC9은 0, 걷기 명령 DNp09는 0~1이었다.
- **눈으로 달아나게 하는 것은 된다.** 같은 입력에서 도약 명령 DNp01이 물체의 크기에 따라 커졌다(조건 5가지를 통틀어 작은 물체 0~10, 중간 1~45, 큰 물체와 다가오는 원판 0~52, 회색 화면 0).
- 시각 뉴런은 자극을 준 쪽 눈에서만 켜졌다(반대쪽 0).

## 잰 것

숫자는 뉴런 하나의 초당 발화 수, 1초, 씨앗 하나다.

**1. 배선 (`lc9_inputs.py`)**: LC9(왼쪽 87개)에 들어오는 시냅스 45,674개 중 flyvis의 65유형이 차지하는 것은 6.6%다. 가장 큰 입력은 중앙 뇌의 억제(PVLP004/005, 18.6%)와 LC9끼리의 연결(13.5%)이고, 시엽에서는 Tm5f(4.8%)가 가장 크다. Tm5f는 flyvis에 없다. 다가옴 뉴런은 다르다: LC4는 61.4%, LPLC2는 39.1%가 flyvis 유형이다.

**2. 광수용체만 켜기 (`t0.py`)**: R1-6을 20, 100Hz로 켜도 LC 계열과 명령 뉴런은 모두 0이다. 발화 모델만으로는 눈에서 신호가 올라오지 않는다.

**3. LC9의 입력을 직접 켜기 (`t1.py`, `t2.py`, `t3.py`)**

| 켠 범위 (200Hz) | 그 LC9 | 걷기 DNp09 | 도약 DNp01 |
|---|---|---|---|
| LC9 1개의 수용야 (22뉴런) | 36.0 | 0 | 16.5 |
| 3개 (62뉴런) | 18.7 | 0 | 67.5 |
| 10개 (335뉴런) | 7.4 | 0 | 98.0 |
| 30개 (966뉴런) | 0.7 | 1.0 | 23.5 |
| 87개 전부 (2,214뉴런) | 0.4 | 4.0 | 39.5 |

- LC9은 자기 수용야만 켜면 발화한다(왼쪽 12개 x 씨앗 2: 평균 55.5, 전부 10 이상. 오른쪽: 평균 45.0, 75%가 10 이상). 켠 범위가 넓어지면 꺼진다. 작은 물체에만 반응하는 셈이다.
- 걷기 명령은 LC9 여럿이 같이 켜져야 나온다: LC9 10개를 150Hz로 직접 켜면 걷기 10, 30개면 33, 전부(지금 게임의 방식)면 76.
- 그래서 작은 물체는 LC9을 몇 개만 켜서 걷기가 안 나오고, 큰 물체는 LC9을 꺼 버린다. 대신 도약이 나온다.

**4. LC31a (`t4.py`)**: 걷기 명령의 둘째 입력이다(DNp09에 338, LC9은 385). LC31a 3개의 수용야(423뉴런)를 200Hz로 켜면 걷기 43, 18개 전부면 116이 나왔다. 눈에서 걷기로 가는 길은 여기에 있다. 다만 LC31a의 가장 큰 입력 Tm21, Tm25는 flyvis에 없다.

**5. flyvis의 출력을 넣기 (`fv1.py`, `inject.py`)**: flyvis의 학습된 망(50개 중 000, 007)에 자극 7가지를 1초씩 넣고, 출력 유형 17종(T2, T2a, T3, T4a~d, T5a~d, Tm1~4, Tm9, Tm20)의 활동을 FlyWire의 같은 유형, 같은 칸 뉴런에 발화 빈도로 넣었다. 대응된 뉴런은 한쪽 눈에 약 7,900개다.

| 자극 (모델 000, 왼쪽 눈, 최대 200Hz) | LC4 | LC9 | LC31a | 걷기 | 도약 (왼/오) |
|---|---|---|---|---|---|
| 회색 화면 | 0 | 0 | 0 | 0 | 0 / 0 |
| 작은 물체, 멈춤 | 0 | 0 | 0 | 0 | 2 / 0 |
| 작은 물체, 지나감 | 0 | 0 | 0 | 0 | 5 / 2 |
| 중간 물체, 지나감 | 1.6 | 0 | 0 | 0 | 13 / 8 |
| 큰 물체, 지나감 | 4.3 | 0 | 0 | 0 | 32 / 33 |
| 다가오는 원판 | 4.6 | 0 | 0 | 0 | 40 / 36 |
| 화면 전체 깜빡임 | 13.3 | 0 | 0 | 1 | 43 / 40 |

오른쪽 눈, 모델 007, 최대 100Hz, 유형 28종으로 바꿔도 LC9과 LC31a는 0, 걷기는 0~2였다. 도약의 크기와 순서는 조건마다 달랐다(예: 오른쪽 눈에서는 큰 물체 0/5, 다가오는 원판 7/8).

## 단서

- 연속 전위를 발화 빈도로 바꾸는 배율은 근거 없이 정했다: 회색 화면 대비 탈분극만 쓰고, 유형마다 자극 묶음의 99.5 백분위를 최대 빈도(100 또는 200Hz)로 맞췄다.
- flyvis의 격자 좌표(u, v)와 FlyWire 칸 표의 (p, q)가 같은 방향이라고 가정했다. 확인하지 않았다. 틀리면 화면이 돌거나 뒤집혀 들어간 것이다(이웃 관계는 유지된다).
- flyvis는 오른쪽 눈의 모델이다. 왼쪽 눈에는 같은 활동을 그대로 넣었다.
- 다가옴을 가려내지 못했다. 깜빡임이 다가오는 원판만큼 도약을 일으킨다.
- 계산 시간과 발화 수: 큰 자극에서 한 틱의 발화가 많게는 48,800번이었다(최대 200Hz일 때). 게임은 20,000번을 넘으면 폭주로 보고 뇌를 되돌린다. 틱 계산도 최대 71ms로 50ms를 넘었다.
- 씨앗 하나, 자극 1초, 학습된 망 2개로 본 것이다.

## 다시 돌리는 법

```
make brain-data                                  (저장소 맨 위에서. 뇌 자료)
cd experiments/eye
gcc -O2 -D_GNU_SOURCE -I../../include -I../.. -o eyeprobe  eyeprobe.c  ../../brain/lif.c -lm
gcc -O2 -D_GNU_SOURCE -I../../include -I../.. -o eyeprobe2 eyeprobe2.c ../../brain/lif.c -lm
PY=../../data/venv/bin/python
$PY lc9_inputs.py                                (저장소 맨 위에서 돌린다: data/raw 를 읽는다)
$PY t1.py && $PY t2.py && $PY t3.py && $PY t4.py  (t1.py가 conn.npz를 만든다)
```

flyvis 쪽은 파이썬 3.12와 flyvis 1.2.0이 필요하다(약 6GB).

```
uv venv --python 3.12 fv && uv pip install --python fv/bin/python flyvis
fv/bin/flyvis download-pretrained
curl -fsSLO https://storage.googleapis.com/flywire-data/codex/data/fafb/783/column_assignment.csv.gz
fv/bin/python fv1.py 000                         (flyvis_act_000.npz)
$PY inject.py 000 left 200 out                   (모델, 눈, 최대 빈도, out=17종 / all=28종)
```

flyvis는 MIT 라이선스의 공개 코드다(Lappalainen 외, Nature 2024). 여기서는 실험에서 불러 쓰기만 했고 게임에는 한 줄도 들어가지 않았다.

## 덧붙임: 참가자가 먹이라면 (맛과 냄새, 11/27)

"참가자를 달콤한 먹이로 두면 쫓아오지 않을까"를 보려고 맛과 냄새의 감각 뉴런을 한쪽만 켰다(`smell0.py`, `smell1.py`).

- **단맛은 먹기만 켠다.** 단맛 감각 뉴런을 120Hz로 켜면 먹기 운동 뉴런이 66~70으로 발화하고, 걷기와 방향 명령은 0이다. 맛은 닿아야 느끼는 감각이라 멀리 있는 먹이 쪽으로 가게 하지는 못한다. 오른쪽 단맛 뉴런만 켜면 먹기도 0이었다(왼쪽만 70, 양쪽 66).
- **냄새는 폭주하거나 아무 일도 없다.** 냄새 감각 뉴런 53유형을 하나씩 왼쪽만 켰다(0.5초). 20Hz에서 30유형, 60Hz에서 43유형이 폭주했다(한 틱 약 43,000번). 폭주한 경우는 어느 유형이든 같은 상태가 되고 방향 명령이 왼쪽만 켜진다. 폭주하지 않은 10유형(DA3, DA4l, DL3, DL4, DM5, VA5, VA7l, VA7m, VM2, VM5v)은 걷기, 방향, 먹기가 모두 0이었다.
- 그래서 이 모델에서 "먹이 쪽으로 간다"를 감각 뉴런에서 시작해 만들 수 있는 길은 찾지 못했다. 지금 게임처럼 물체 뉴런(LC9)을 직접 켜는 방법만 걷기를 낸다.
- 쓸 수 있는 것: 초파리가 참가자에게 닿았을 때 단맛을 주면 "먹을지"를 뇌가 정한다. 쓴맛을 같이 주면 먹기가 꺼진다(docs/guide.md의 표).
